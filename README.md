## 👋 About Me

I'm a **Full Stack Developer** who enjoys building applications from both sides of the screen — from designing how users interact with a system to figuring out how everything works behind it.

I like understanding the **problem behind a feature**, breaking it into clear workflows, and turning it into something that is practical, maintainable, and actually useful.

For me, good development isn't only about making something work.

It's about asking:

- What problem are we actually solving?
- How should this flow work for the people using it?
- How can the system stay simple as it grows?
- What happens behind the scenes when things change?

> 少しずつでも、前に進む。  
> *Even little by little, keep moving forward.*
